## نحوه جایگزینی تصاویر

### مرحله ۱: آماده‌سازی تصاویر
- تصاویر غذا: حداقل **800x600** پیکسل، نسبت **4:3**
- تصویر Hero: حداقل **1600x900** پیکسل
- لوگو: **200x200** پیکسل با پس‌زمینه شفاف (PNG)
- فرمت: **JPG** یا **PNG**

### مرحله ۲: قرار دادن تصاویر
1. تصاویر را در پوشه مربوطه کپی کنید
2. نام فایل‌ها را **دقیقاً** مطابق لیست بالا قرار دهید

### مرحله ۳: فعال‌سازی تصاویر محلی
فایل `src/config/images.ts` را باز کنید و این خط را تغییر دهید:

```typescript
// قبل:
export const USE_LOCAL_IMAGES = false;

// بعد:
export const USE_LOCAL_IMAGES = true;
```

### مرحله ۴: بازسازی پروژه
```bash
npm run build
```

## نکات مهم

### کیفیت تصاویر
- از تصاویر با کیفیت بالا و نورپردازی مناسب استفاده کنید
- تصاویر باید بدون واترمارک باشند
- رنگ‌ها باید طبیعی و اشتهابرانگیز باشند

### بهینه‌سازی
- حجم هر تصویر حداکثر **500 کیلوبایت** باشد
- از ابزارهای فشرده‌سازی مانند TinyPNG استفاده کنید

### نسبت تصویر
- تصاویر غذا: **4:3** یا **16:10**
- تصویر Hero: **16:9**
- لوگو: **1:1** (مربع)

## تصاویر فعلی

در حال حاضر، سایت از تصاویر آنلاین (Pexels) استفاده می‌کند. برای استفاده از تصاویر اختصاصی خود، مراحل بالا را دنبال کنید.
